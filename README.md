# 📊 PhonePe Transactions Data Analysis using Power BI

## 📌 Project Overview
This project focuses on analyzing **300K+ PhonePe transaction and user records** using **Microsoft Power BI**.
The objective was to transform raw transaction and user data into an interactive business intelligence dashboard for monitoring **KPIs, transaction trends, payment performance, service performance, and user behavior**.
The project demonstrates an end-to-end Power BI workflow, including **data import, data cleaning, data transformation, data modeling, DAX calculations, interactive visualization, business analysis, and report publishing to Power BI Service**.

---

## 🎯 Objective
The primary objectives of this project were to:
- Analyze PhonePe transaction performance and monthly trends.
- Monitor key KPIs such as total transactions, transaction value, unique users, and successful transaction rate.
- Analyze transaction performance across different services and payment statuses.
- Identify major reasons for unsuccessful transactions.
- Understand user behavior across different age segments.
- Identify top users based on transaction value.
- Derive actionable business insights from the analysis.
- Build an interactive dashboard for easy business reporting and decision-making.

---

## 📂 Dataset Description
The dataset was imported from **Microsoft Excel** with two tables:
### Transaction Table
Contains **300K+ records** with information related to PhonePe transactions, such as Date, Transaction Amount, Service Used, Payment Status

### User Table
Contains **100K+ records** with information related to users, such as Username, Age, Joining Date

## 📊 Dashboard / Key Features
The interactive dashboard provides the following key features:

### 📌 KPI Cards
- **Total Transactions:** 300K+
- **Total Transaction Value:** ₹3.47 Billion
- **Unique Users:** 108K
- **Successful Transaction Rate:** 98.40%

### 🎛️ Interactive Filters
- Monthly analysis through a **Month slicer**
- Payment status filtering, including **Successful, Failed, and Other transactions**

### 📈 Visualizations
- **Transactions Over Time** – Tracks monthly transaction volume and transaction value.
- **Unsuccessful Transaction Reason Analysis** – Identifies major reasons behind unsuccessful transactions.
- **Service Transaction Value Analysis** – Compares transaction value across services such as Loans, Insurance, Money Transfer, and Recharge Bills.
- **Top 5 Users by Transaction Value** – Identifies users with the highest transaction values.
- **Age Segment Contribution** – Analyzes user distribution across different age segments.
- **Interactive Tooltips** – Provides additional details when users interact with dashboard visuals.
- **KPI Cards** – Provides a quick overview of important business metrics.

---

## 💡 Key Insights
- The dashboard recorded **300K+ total transactions** with a total transaction value of approximately **₹3.47 Billion**.
- The overall successful transaction rate was **98.40%**, indicating strong transaction success performance.
- **Loans** recorded the highest transaction value among the analyzed services, contributing approximately **₹2.5 Billion**.
- Among unsuccessful transactions, **Server Errors, Wrong PIN, and Insufficient Amount** were the major contributing reasons.
- Users aged **26–58** represented approximately **three-fourths of total users**.

---

## 🚀 Business Recommendations
- 🔧 Reduce transaction failures by addressing major failure reasons.
- 🏦 Focus on high-value services such as **Loans**.
- 🎯 Develop targeted strategies for the core **26–58 age segment**.
- 📊 Monitor monthly KPIs and retain high-value users.
